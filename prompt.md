# 🚀 Prompts de Desenvolvimento: Projeto ArtChain Web3

Este ficheiro regista a sequência de prompts e orientações utilizadas para a construção da plataforma **ArtChain** durante o ciclo de 5 dias (Descoberta, Estruturação, Planeamento Blockchain, Construção e Pitch).

---

## 🟢 DIA 1: Descoberta e Ideação
**Objetivo:** Definir o problema e a proposta de valor.
> **Prompt utilizado:** > "Atua como um especialista em Web3 e Gestão de Projetos. Ajuda-me a idealizar uma plataforma para artistas independentes que resolva o problema das altas taxas bancárias e falta de rastreabilidade. A solução deve usar a rede Solana e incluir uma secção educativa e um gerador de ideias para combater o bloqueio criativo."

---

## 🟣 DIA 2: Estruturando a Solução
**Objetivo:** Mapear a jornada e o fluxo técnico.
> **Prompt utilizado:**
> "Cria um fluxo de utilizador (User Journey) para a plataforma ArtChain. O fluxo deve começar na Landing Page, passar por um Hub de Melhoria (tutoriais), um Gerador de Ideias e terminar num Marketplace onde o pagamento é feito em SOL com captura automática de geolocalização e timestamp para segurança."

---

## 🔵 DIA 3: MVP & Blockchain
**Objetivo:** Definir a stack tecnológica e o que é essencial.
> **Prompt utilizado:**
> "Define o MVP (Produto Mínimo Viável) para o ArtChain. Explica porque a Solana é a melhor escolha técnica (taxas e velocidade) e como podemos usar os metadados das transações para gravar a localização do comprador. Indica o que devemos cortar do projeto para lançar rapidamente (ex: remover chats e leilões)."

---

## 🛠️ DIA 4: Construção
**Objetivo:** Gerar o código base e organizar a arquitetura.
> **Prompt utilizado:**
> "Gera um código base em React.js utilizando Tailwind CSS para a interface. O site deve ter um Header com o perfil do Admin (suporte), uma secção de Hub de Melhoria e um Marketplace funcional. Integra a biblioteca @solana/web3.js para conexão de carteira e usa a Geolocation API do browser para capturar latitude e longitude no momento do clique de compra."

---

## 🏁 DIA 5: Finalização & Pitch
**Objetivo:** Refinar o produto e criar a narrativa de venda.
> **Prompt utilizado:**
> "Cria um roteiro de Pitch para o ArtChain. O texto deve ser focado em investidores e artistas, destacando como resolvemos a exploração financeira atual. Finaliza com uma lista de entregáveis detalhados dos 5 dias de projeto para colocar no README do GitHub."
